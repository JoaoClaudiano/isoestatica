# Isostática Lab

Laboratório Virtual de Análise de Estruturas Isostáticas

## Descrição

Ferramenta educacional interativa para análise de estruturas isostáticas, desenvolvida para estudantes de Engenharia Civil. Permite modelar, analisar e visualizar o comportamento de vigas, pórticos, grelhas e arcos isostáticos.

## Funcionalidades

### Tipos de Estruturas Suportadas
- **Vigas Isostáticas**: Análise de esforços cortantes e momentos fletores
- **Pórticos Planos**: Diagramas de esforço normal, cortante e momento fletor
- **Grelhas Isostáticas**: Momentos fletores, torçores e forças cortantes
- **Arcos Isostáticos**: Linha de pressão e esforços internos

### Recursos Principais
- Modelagem gráfica interativa
- Cálculo automático de reações de apoio
- Geração de diagramas de esforços internos
- Visualização da forma deformada
- Exemplos pré-configurados
- Interface intuitiva e responsiva
- Exportação de resultados

## Tecnologias Utilizadas

- HTML5, CSS3, JavaScript puro
- Canvas API para renderização gráfica
- ES6+ com módulos JavaScript
- Design responsivo
- Hospedagem estática (GitHub Pages)
